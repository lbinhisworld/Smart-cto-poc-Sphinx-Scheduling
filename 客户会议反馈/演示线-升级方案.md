## 1. 为什么要做

- **路径**：17 步 PC 列表 + 顶栏「生成数据 / 下一步 / 反馈」。  
- **谱系**：每步造数记入演示线，反馈可挂实体与 story #1–5。  
- **拟真**：词库驱动，禁止「销售李」「测试001」等展示名。  
- **导出**：结束一键 MD → Cursor；解析员只收「待解析员」节，须人确认后再封印。

---

## 2. 原则摘要

1. 仅 **ACTIVE** 演示线显示顶栏。  
2. 演示数据 ≠ 封印事实。  
3. **不写回** `so_order.due_date`（BR-27）。  
4. **终局是订单生产成本核定**；计件发薪在客户侧，**Excel 导入为将来输入**，并入实际人工，**不占演示步、本期不建设**。

---

## 3. 演示路径（17 步）

人员 → 产品(BOM) → 客户 → 陌生拜访 → 商机 → 跟进 → 打样 → 报价 → 合同回款 → 转订单 → 排产 → 派工 → 报工 → 二次排产 → 品控 → 入库 → **订单生产成本核定**。

---

## 4. 演示管理（/demo）

新建 / 启动 / 结束（总经理）；进行中任何人可反馈；导出 MD。

---

## 5. P0 已交付能力

- 表：`demo_run`、`demo_run_seed_event`、`demo_run_feedback`、`demo_run_step_snapshot`  
- **启动**：清空本线未归档谱系/反馈，从第 1 步重来  
- **生成数据**：替换本环节旧谱系（每步仅保留最新一批 5 条故事线）；P1 起同步清模块业务存量  
- **结束**：各环节快照写入 `demo_run_step_snapshot`  
- **重放**：只读快照走链；不可生成数据；可下一步 + 追加反馈；反馈弹窗含本环节时间线  
- **导出**：按钮「导出演示过程 md」，含各环节反馈时间线  
- 词库：`seed/guided_demo_lexicon.json`
