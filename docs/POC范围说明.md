## M1b 生产成本（POC）

- **报工**：按已发布计划列出**有任务且未确认人·时**的日期时间线（不选手动选日）；节点下只显示当天有计划的组。班组长确认该组 **实际总人·时**；任务抽屉另报 **完工版数**（BR-01 先归一到版）。
- **未完回池**：计划 100 / 完工 80 → 剩余 20 进待确认池（工单 `PARTIAL`），**不改**订单交期、**不**自动次日重排。PMC/GM 二选一：并入同品项下次生产，或按剩余版数插单（`PIN_FIRST`）。不做取消尾数。
- **防虚报**：报工人·时不得超过当日该组考勤上限（组出勤实到 × 日历日工时）；无考勤记录则拒绝确认。
- **核算**：`hr_labor_rate` 标准单价（元/人·时）；人事「生产成本」页按部门-组汇总差异。
- **权限**：班组长仅本组；PMC/GM 可跨组代填并处理尾数；HR/FIN 只读汇总。
- **不做**：完整薪酬、按员工报工、报工确认后自动重排、取消尾数。

## 出勤 → 产能 & 产品人工成本（A/C 链路 POC）

- **A 出勤→排程**：考勤页「同步到排程产能」写入 `hr_group_attendance`；倒排/试算读 `headcount_present` 约束并行人力与（可配置）组×日墙钟上限（`config/schedule.yaml` · `attendance_scale_day_hours`）。
- **C 产品成本**：已发布计划按 `wo_task.hours_man × 标准单价` 汇总到**成品品项**；驾驶舱 Top 品项、BOM 页计划成本卡片、`GET /api/hr/labor-cost/by-product`。

## 演示与待办（Phase 8）

- **演示控制台** `/demo`：场景台（初始化订单 / 初始产线人员 / 生成测试订单集，基准日 2026-09-15）、产销财务闭环步骤、十幕剧本、S5 打样超期触发（写操作仅 GM）
- **待办中心** `/todos`：按角色聚合变更待批、排程池、打样超期、企微未读、低齐套、人事合同到期等
- **人事合同**：花名册展示续签三态（正常 / 一个月内续签 / 续签过期）指标图并可穿透名单；档案详情含下次续签倒计时；HR/GM 待办提醒
- **打样过程子表**：持续追加环节记录；打样环节自动在产品名后标注琥珀色「第 N 轮」；可勾选「本轮复打」沿用同轮；最后定稿须留证据并结案
- **CTP**：销售按任意品项/数量/单位/交期试算；新建订单可对全部明细 + 整单交期做一次同池预检（不落库、不拦截保存）
- **辅助调整**：排程冲突区「过程」Tab 回放倒排记录；E1/E2 可发协商口径（不改交期）→ 销售待办/企微模拟 S6 → 销售回确认日 S7 → PMC 改锚 S8 后再倒排；订单「交期动态」时间线留痕。真企微机器人不在 POC
- **同品项共线（A/B）**：场景单按行进排程；同组同日同品项青绿标并线点，过程写并线决策，汇总「K 个点 / M 版」。人确认 LOT 合批（C）待门槛确认后做
- **数据**：`seed/seed_data.json` + `seed/demo_data.json`；本地 SQLite，断网可演示

## M2b 合同与回款（POC）

- **合同**：客户 360 内历史合同、侧滑详情（计划/回款/关联订单）、新建合同（自动编号 + 回款计划）
- **回款**：登记回款、计划行状态（含逾期）；待办中心「待回款」提醒（FIN/销售）
- **订单**：新建/金蝶 Mock 进单须关联 **ACTIVE** 合同；客户列表渠道/级别/已收待收指标
