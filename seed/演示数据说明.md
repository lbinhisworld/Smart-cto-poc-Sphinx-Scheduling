## 订单池四 Tab（待排程 → 排程中 → 生产中 → 已完结）

- 种子默认 **3 单在「排程中」**（SO-001 / SO-002 / SO-003），其余在「待排程」。
- **待排程**：勾选 → **加入排程中**（整池同进退，不支持部分发布）。
- **排程中**：按交期升序 → **试排** → 黄/灰冲突可带预警 **保存发布**；**E1/E2 红冲突禁止发布**。
- **生产中**：改交期仅走改单/插单，不会自动回到待排程。
- 插单演练：将 **SO-004、SO-005** 加入排程池后试排，观察涟漪与冲突，再拖拽/沙箱调整。

## 演示建议

1. **排程池试排发布**：「排程中」Tab → 试排 → 确认计划完工日 → 保存发布 → 订单进入「生产中」。
2. **全池倒排（不落发布）**：排程中池有单时顶栏「一键倒排」仅对池内订单落库看板。
3. **核心三单回归**：排程中池仅 SO-001~003 时试排，结果与阶段 1~2 文档一致。
4. **E2 演示**：仅 SO-002，交期改为 `2026-09-23` 再倒排。
5. **库存覆盖**：SO-201（P5）有 S5 库存 200，二部任务量会小于毛需求。
6. **库存中心**：顶栏「库存中心」改 S2 数量 → 再倒排看 SO-002 半成品净需求变化；「模拟 ERP 同步」恢复 mock。
7. **齐套 / 多子件 BOM**：P2 含 S2（SEMI）+ PKG-P2（外购）；倒排后订单池看齐套 ✓/✗，点「齐套详情」；冲突面板可见 E9/E10。
8. **多半成品**：工艺/BOM 选 **P9** 或订单 **SO-303** → 展开数量可见 4 行子件；全单倒排后在订单视图见 S2/S5/S6 三条二部任务。
