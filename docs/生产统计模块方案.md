# 生产一部 / 二部统计模块方案

统计从报工、考勤、入库派生，禁止再开一张可编辑 Excel。查询放在 `db/prod_stats.py`，**不进** `engine/`。排程颗粒度仍是**工作中心 × 天**（一部三组是产线，不是工序链；客户目标报工是工序×中心，统计一期不升维）。与并行 [Wave X](../客户会议反馈/工艺口径与量产成本隔离-升级方案.md) 一致。

## 一部（已落地）

路径：`/modules/production/stats/dept1`  
角色：班组长 / PMC / GM / 仓 / 人事财务只读

### 锁定口径

- 盒/H 分母 = 直接正常 + 直接加班，**不含间接**
- 每品项单独克重：`盒当量 = qty_actual_board × kg_per_board`（报工日 `wo_task.kg_per_board_snap` 优先）
- 未报工格子为空；不用计划顶实际
- 有工时无数量或有数量无工时：当日盒/H 为空
- 区间盒/H = Σ已报工日盒当量 / Σ已报工日直接工时（三组先加总再除，不平均各组盒/H）
- 缺克重：原单位可显示，不进盒当量合计

### 三页签

1. 日产出明细：组 × 类（手工模具/棒子/切片/糖花/logo…）× 展示单位 × 日
2. 一部日结：产能 / 入库 / 差异 / 领用 / 出勤工时 / 按单位汇总
3. 盒当量与效率：组盒/H + 按日明细

完工报工带 `work_date` 时回写当天任务 `qty_actual`。入库 mock：`POST /api/prod-stats/dept1/inbound`。

拟真数据：`db/prod_stats_seed.py` 灌 9/1–9/25 工作日已报工（产量与工时错开起伏），9/28–9/30 仅计划。工单 `WO-D1S-*` / `plan_version=9001`，不进排程看板。打开统计页或重启后端即写入。
