# 工艺口径与量产成本隔离 · 升级方案（并行 Wave X）

> 2026-09 会后逐字稿 + 客户书面四条（工序树 / 实际成本 / 打样进项目 / 费用分期）。  
> **并行专题，不替代、不抢跑 Wave 3（二部拆组）/ Wave 4（设备+关键岗额度）。**  
> 无标准工序清单前 **禁止改 `GroupCode`**。禁止写回 `so_order.due_date`（BR-27）。一期不做 APS。

## 1. 为什么单独成波

Wave 3 原假设「二部拆成原料→生巧→半成品三条排程组」。客户后来补了两件事：

1. **一部三个组不是 1→2→3**，多数是一品一组做完再包装；组装没有独立组。
2. **工序 ≠ 工作中心 ≠ 报工**。报工目标颗粒度是「工序 × 工作中心」。再按组名拆引擎，会把两维焊死，成本中心还得拆一次。

因此：已锁死的口径先落文档和一条小实现；拆组仍等生产清单。

## 2. 本波做什么

| 步 | 做什么 | 对外一句话 |
|----|--------|------------|
| **X-A** | 把已确认口径写进总计划 / POC 范围 / 统计方案 | 一部是产线；三级映射是目标；倒排仍组×天 |
| **X-B** | 量产品项成本剔除打样 / 失败轮次工时 | 量产成本干净；打样进费用，不进品项 |
| **X-C** | 看板/BOM 文案对齐（不改算法） | 二部片材可流向一部三组；一部组不是工序链 |

X-A = 本文件与总计划补丁。X-B / X-C 已落地：量产成本接口剔除 `SAMPLE`/`RND` 及报价挂打样单；看板/BOM 写明一部产线与二部片材流向。

## 3. 已锁定口径（可对外说）

### 3.1 一部组 = 工作中心，不是工序链

- 手工 / 模具 / 浇筑是三条产线。多数品只在其中一个组做完，再去包装、入成品仓。
- 少量：多组做配件，在主配件所在组组装。**没有独立组装组。**
- 现有「一品项绑一个 `GroupCode`」继续当默认，覆盖多数路径。
- **本期不加包装组、不做多组配件路由**（确认有包装，未确认占产能）。

### 3.2 二部 → 一部

- 二部半成品片材 / 印刷车间产出 **可以流向一部全部前端**（手工、模具、浇筑）。
- 齐套/半成品库存按品项引用即可，不把二部焊死到某一个一部组。
- 原料 / 生巧 / 半成品 / 印刷 哪些是工序、哪些是工作中心：**未确认，不改引擎。**

### 3.3 三级映射（目标架构，本期不建树）

| 层 | 管什么 | 本期 POC |
|----|--------|----------|
| 工序树 | 产品怎么做（与机器、人无关） | 等生产给标准清单；**不编假树** |
| 工作中心 | 用什么资源（班组/产线/设备组，与产品无关） | 现有组 = 看板一行、日历、SPH、组×日报工 |
| 报工单元 | 谁在何时做了多少 = **工序 × 工作中心** | 现报工只有工作中心×日；升维等清单 |

一道工序可绑多个中心；一个中心可接多道工序。缺一维不能报工——这是验收后的 MES 口径，不是当前倒排输入。

### 3.4 成本

- **禁止**用标准 backflush 倒挤半成品→成品来掩盖工序浪费。
- **现状必须写明**：产品成本仍是 `hours_man × 标准人时单价`，不是实际成本结转。
- 排程展量继续用标准损耗（BR-02 / BR-31）——那是「要做多少版」，不是结转。
- 打样工时、失败轮次：**归部门/项目费用，不摊进量产品项。** 项目 ROI 整页仍待设计。
- 制造费用一期主线：人工效率 + 设备占位；水电辅助监控。**不做** OEE 公式、折旧计提、电费分摊（等生产回复）。设备占位 ≠ Wave 4 排程额度。

## 4. X-B 实现要点（先测后改）

现状：[db/product_labor_cost.py](../db/product_labor_cost.py) 按 `so_order` / 工单品项汇总；打样在 `crm_sample`，**没有**自动隔离。

建议识别（实现时用测试钉死一种，禁止猜）：

1. 订单 `order_source = SAMPLE`（或等价），或
2. 报价 `crm_quote.sample_code` 已转到该订单，或
3. 工单/任务显式 `cost_bucket = SAMPLE | RND`

量产接口（驾驶舱 Top 品项、`GET /api/hr/labor-cost/by-product`、BOM 计划成本）默认只含量产。打样合计可另字段 `sample_excluded`，不并进品项。

引擎不读此标记。禁止为了隔离去改 `due_date`。
