# 售前答复 · 实施与培训（一体化 POC 口径）

本文档用于售前/验收场景，与 `docs/POC范围说明.md` 及演示控制台 `/demo` 九幕剧本一致。

## 1. 实施范围与周期（POC → 一期）

| 阶段 | 内容 | POC 已验证 | 一期建议 |
|------|------|------------|----------|
| 基础平台 | 角色、菜单、审计、双进程部署 | 是 | 生产账号与 SSO 对接 |
| 订单与 CRM | 档案、漏斗、CTP、变更影响 | 是 | 与销管 Excel 字段对齐评审 |
| 计划与排程 | 倒排、齐套、插单、导出派工 | 是 | 与金蝶/库存真接口 |
| 集成 | 金蝶 Push、ERP 库存 | Mock | 联调窗口 + 异常重试 |
| 移动/企微 | 消息、日程提醒 | 本地模拟 S1–S5 | 真企微应用（不在 POC） |

POC 目标：**流程可讲清、关键 BR 可演示**；不是替换全部 Excel 或一次上全模块。

## 2. 数据与迁移

- POC 使用内置种子 + 可选 `reset_db.sh`，**不包含**入微云历史全量迁移。
- 一期迁移建议：主数据（物料/BOM/客户）分批；订单在 cutover 周冻结导入；排程计划以新系统生成为准。

## 3. 培训安排（建议 3 天压缩版）

**Day 1 · 销售与 PMC 协同**

- 上午：CRM 漏斗、样品、CTP 试算（第 5 幕）
- 下午：订单变更、影响清单、PMC 审批（第 7 幕）；强调交期锚 BR-27

**Day 2 · 计划员**

- 金蝶进单 → 齐套 → 待排产池（第 3–4 幕）
- 倒排看板、试排/Sandbox、导出派工（第 6 幕）
- 插单四策略（第 8 幕）

**Day 3 · 管理层与验收**

- 驾驶舱 M1–M7、现状对照（第 1、9 幕）
- 待办中心、演示控制台走完整九幕
- 明确五类不交付项，签署范围边界

## 4. 环境与离线演示

- 笔记本单机：`./scripts/start.sh` + `cd web && npm run dev`（5180）
- 无需外网；企微/金蝶/ERP 均为 Mock，话术见演示控制台免责声明

## 5. 常见售前问题（简答）

**Q：会不会一改计划就把所有订单交期改掉？**  
A：不会。系统交期以订单为准，排程只动工单与任务；改交期必须走变更审批（BR-27）。

**Q：产能不够会不会排不出？**  
A：会给出冲突预警（E1–E8）与最快可交期提示，不 silent 失败（BR-47/50）。

**Q：能否拖拽配置审批流？**  
A：POC 为固定流程演示；可视化设计器不在本期范围。

**Q：报表能否自定义？**  
A：本期为预置驾驶舱与 Excel 导出；自定义报表设计器不在本期。

## 6. 验收建议（G1–G5 抽查）

1. 九幕剧本 `/demo` 可由 GM 角色 45–60 分钟讲完  
2. 销售改交期 → PMC 批准 → 订单详情 due_date 变化，且倒排结果随之变化  
3. 插单试排四策略 diff 可见，应用后 plan_version 递增  
4. `pytest -q` 与前端 `npm run build` 通过（交付物自检）  
5. 书面确认「五类不交付」与 CRM MUST 清单映射（见 POC 范围说明）
